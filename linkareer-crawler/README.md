# 링커리어 식품·건강 공고 수집기

링커리어의 **공모전**과 **대외활동** 목록에서 식품, 영양, 건강 관련 공고만 골라 Google 스프레드시트에 저장합니다. 엑셀 파일로도 함께 저장합니다.
매주 월요일과 목요일 오전에 GitHub Actions로 자동 실행됩니다.

## 동작 방식

1. `/list/contest`, `/list/activity`의 최신순 목록을 앞에서부터 N페이지(`config.yaml`의 `pages_per_list`) 읽습니다.
2. 처음 보는 공고만 상세 페이지를 열어 주최사, 마감일, 분야, 본문, 포스터를 가져옵니다.
3. 아래 기준으로 점수를 매겨 **4점 이상은 추천, 2~3점은 검토**로 시트에 넣습니다. 점수 자체는 시트에 쓰지 않고, 어떤 조건에 걸렸는지만 `추천이유` 열에 적습니다.
   | 조건 | 점수 | 추가하는 곳 |
   |---|---|---|
   | 관심 기업·기관이 주최 | +4 | `설정` 탭 `관심기업` / `config.yaml` `organizations` |
   | 링커리어 분야가 관심분야 (기본: 요리/식품) | +4 | `설정` 탭 `관심분야` / `categories` |
   | 링커리어 분야가 참고분야 (기본: 의료/보건, 체육/헬스) | +2 | `설정` 탭 `참고분야` / `sub_categories` |
   | 주최사 이름에 식품, 제약, 헬스 같은 업종 단어 | +3 | `설정` 탭 `주최키워드` / `organizer_keywords` |
   | 제목에 키워드 | 키워드당 +2 (최대 +4) | `설정` 탭 `키워드` / `content_keywords` |
   | 본문에 키워드 | 키워드당 +1 (최대 +3) | 위와 같음 |
   | 제외 키워드 ("금융 건강" 등) | −3 | `설정` 탭 `제외키워드` / `exclude_keywords` |
   | 제외 기업 | 항상 제외 | `설정` 탭 `제외기업` |
4. 추천·검토 공고는 `내용요약`(무엇을 하는 공고인지), `준비할 것`, `참가대상`을 채웁니다.
   - **Gemini(무료 등급)**: GitHub Secret `GEMINI_API_KEY`가 있으면 Gemini가 포스터 이미지와 본문을 읽고 한 문장씩 정리합니다.
     예) "국내산 양식 수산물로 만든 요리를 겨루는 대회" / "요리 영상(10분 이내) + 완성 사진 제출" / "누구나"
     - 한 번 실행에 최대 40건, 요청 사이 7초 간격이라 무료 한도 안에서 동작합니다.
     - `gemini-2.5-flash` → `gemini-2.5-flash-lite` → 최신 Flash 순으로 시도합니다. 결제가 필요한 모델(402)이나 없는 모델(404)은 건너뜁니다.
     - 쓸 수 있는 모델이 없거나 한도를 넘으면 그 실행의 나머지는 **빈칸 대신 발췌로** 채우고, 다음 실행 때 다시 문장 요약을 시도합니다. 실패해도 기존 요약은 지우지 않습니다.
     - 모든 모델이 402(결제 필요)로 거절되면, 키를 만든 구글 클라우드 프로젝트에 결제 설정이 걸려 있을 수 있습니다. AI Studio에서 **새 프로젝트로 키를 다시 만들어** Secret을 바꿔 보세요.
     - 무료 등급은 입력한 내용이 구글 서비스 개선에 쓰일 수 있습니다. 링커리어 공개 공고만 보내므로 개인정보는 없습니다.
   - 키가 없으면 아래 무료 발췌로 채웁니다.
   - `(발췌)`: 본문을 ■, [ ], ✅ 같은 제목 단위로 나눠 "공모 주제", "활동 내용", "필수 제출", "지원 방법" 등의 항목을 잘라 넣습니다. 약 90%의 공고는 본문 글이 있어 이 방식으로 채워집니다.
   - `(포스터 OCR)`: 본문 글이 거의 없고 포스터 이미지뿐인 공고(약 10%)는 무료 OCR(Tesseract)로 이미지 글자를 읽어 같은 방식으로 발췌합니다. 오타가 섞일 수 있습니다.
   - (선택) Gemini 대신 GitHub Secret `ANTHROPIC_API_KEY`를 등록하면 Claude가 같은 방식으로 요약합니다 (유료).
5. 매 실행마다 시트 전체를 **구분 → D-day 가까운 순**으로 다시 정렬합니다. **마감일이 지난 공고는 시트에서 삭제**하고, `_seen`에 기록해 다시 들어오지 않게 합니다. (삭제되는 행의 상태·메모도 함께 사라집니다.)
   - `상태`, `메모` 칸과 직접 추가한 열은 그대로 보존됩니다.
6. 제외·마감 공고는 `_seen` 탭에 ID만 기록해서 다음 실행 때 다시 읽지 않습니다.

## 시트 `설정` 탭 (검색 조건)

첫 실행 때 비어 있는 `시트1`을 `설정` 탭으로 바꾸고, 현재 쓰는 조건 전체(관심기업 약 80개, 키워드 약 40개 등)를 옮겨 적습니다. 오른쪽(E~G열)에는 조건별 점수 설명 표가 붙습니다.
**그 뒤로는 이 탭이 기준**입니다. A~B열에 `구분`과 `값`을 한 줄씩 추가하거나 지우면 다음 실행부터 반영됩니다. `config.yaml`은 처음 옮겨 적을 때만 쓰입니다.

`구분`에 쓸 수 있는 값: `관심기업`, `관심분야`, `참고분야`, `주최키워드`, `키워드`, `제외키워드`, `제외기업`

- 관심분야와 참고분야는 링커리어 분야명과 **똑같이** 적어야 합니다. 메인 탭 `분야` 열에 나온 이름을 그대로 복사하세요.
  - 예: 요리/식품, 의료/보건, 체육/헬스, 뷰티/미용/화장품, 기획/아이디어, 광고/마케팅, 서포터즈
- 새 기준은 **이후에 새로 올라오는 공고**부터 적용됩니다. 이미 제외된 공고까지 다시 보려면 `_seen` 탭의 2행부터 아래를 지우고 실행하세요.
- `re:`로 시작하는 값은 특수 패턴(정규식)이라 그대로 두세요.

## 비용

| 항목 | 비용 |
|---|---|
| GitHub Actions (공개 저장소) | 무료. Run workflow를 몇 번 눌러도 무료 |
| Google Sheets API | 무료 |
| 링커리어 수집 | 무료 |
| 본문 발췌 + 포스터 OCR 요약 | 무료 |
| Gemini 문장 요약 (`GEMINI_API_KEY`) | 무료 등급 한도 안에서 무료 (결제수단 등록 안 하면 과금 없음) |
| (선택) Claude 요약 (`ANTHROPIC_API_KEY` 등록 시만) | 추정 공고 1건당 약 $0.02~0.05, 월 $3~5 안팎 (claude-opus-5-5 기준) |

- 아래는 Claude 요약을 켤 때만 해당합니다. Claude 요약 비용은 추천·검토 공고에만 발생합니다. 한 번 요약한 공고는 다시 요약하지 않습니다.
- 한 번 실행에 최대 `max_per_run`(기본 40)건으로 상한을 걸어 두었습니다.
- `config.yaml`의 `summary.model`을 `claude-haiku-4-5`로 바꾸면 비용이 약 1/4로 줄지만, 포스터를 읽는 정확도는 떨어질 수 있습니다.

## Google 스프레드시트 연동 (처음 한 번만)

1. [Google Cloud Console](https://console.cloud.google.com/)에서 프로젝트를 만들고 **Google Sheets API**를 사용 설정합니다.
2. IAM 및 관리자 → 서비스 계정 → 계정 생성 → 키 → **JSON 키 추가**를 눌러 파일을 받습니다.
3. 스프레드시트를 하나 만들고, 서비스 계정 이메일(`xxx@xxx.iam.gserviceaccount.com`)에 **편집자로 공유**합니다.
4. 스프레드시트 주소 `https://docs.google.com/spreadsheets/d/<이 부분>/edit`에서 `<이 부분>`이 `SPREADSHEET_ID`입니다.

### GitHub Actions로 자동 실행 (추천: PC를 켜 둘 필요 없음)

저장소 Settings → Secrets and variables → Actions에 아래를 등록합니다.
- `SPREADSHEET_ID`: 위 4번에서 확인한 값
- `GOOGLE_SERVICE_ACCOUNT_JSON`: JSON 키 파일 내용 전체
- `GEMINI_API_KEY` (권장): 문장 요약용. [Google AI Studio](https://aistudio.google.com/apikey)에서 결제수단 없이 발급합니다.
- `ANTHROPIC_API_KEY` (선택): Claude 요약용. [console.anthropic.com](https://console.anthropic.com)에서 발급합니다. Claude 구독과는 별도로 선불 충전이 필요합니다.

일정은 `.github/workflows/linkareer-crawler.yml`에 정의되어 있습니다 (월·목 08:47 KST).
Actions 탭에서 **Run workflow**를 누르면 바로 실행해 볼 수 있습니다. 실행마다 새로 추가된 공고가 엑셀 파일로 Artifacts에 올라갑니다.

### 로컬에서 실행

```bash
cd linkareer-crawler
python -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt

python main.py --excel-only            # 엑셀만 저장 (output/linkareer.xlsx, 누적)
# 구글시트 연동: JSON 키를 service_account.json 으로 이 폴더에 두고
SPREADSHEET_ID=스프레드시트ID python main.py
```

포스터 OCR을 로컬에서도 쓰려면 Tesseract를 설치해야 합니다. 설치하지 않으면 OCR만 건너뛰고 나머지는 그대로 동작합니다.
- Windows: [UB-Mannheim 설치 파일](https://github.com/UB-Mannheim/tesseract/wiki)로 설치하고, 설치 중 Korean 언어 데이터를 선택합니다.

로컬에서 월·목 자동 실행을 하려면:
- macOS/Linux: `crontab -e`에 `47 8 * * 1,4 cd /경로/linkareer-crawler && .venv/bin/python main.py`를 추가합니다.
- Windows: 작업 스케줄러에서 매주 월·목 트리거로 `.venv\Scripts\python.exe main.py`를 등록합니다. 시작 위치는 이 폴더로 지정합니다.

## 옵션

| 옵션 | 설명 |
|---|---|
| `--dry-run` | 저장하지 않고 매칭 결과만 출력합니다 |
| `--pages N` | 목록을 N페이지까지 읽습니다 |
| `--no-detail` | 상세 페이지를 열지 않습니다 (빠르지만 정확도가 떨어짐) |
| `--dump` | 받은 HTML을 `debug/`에 저장합니다 (사이트 구조를 확인할 때) |

## 한계와 주의사항

- 2026-09 기준 실제 사이트 구조로 확인했습니다. 목록과 상세 페이지의 `__NEXT_DATA__` 안 `__APOLLO_STATE__`에서 `Activity` 객체를 읽습니다.
  - 목록 한 페이지에는 공고 20건과 광고 약 7건이 들어 있고, 모집 중인 공고만 나옵니다.
  - 포스터는 상세 페이지의 파일 목록(유형 2)에 있고, 본문에 이미지가 있으면 함께 요약에 씁니다.
- 사이트가 개편되면 목록이 0건이 되고 실행이 실패로 표시됩니다. 그때는 `--dump`로 HTML을 받아 필드명을 다시 맞춰야 합니다.
- 첫 실행(5페이지 × 2개 목록)은 상세 페이지 요청 때문에 10분 가까이 걸립니다. 그다음부터는 새 공고만 읽어서 금방 끝납니다.
- GitHub Actions 서버 IP가 사이트에서 차단되면 목록이 0건이 되고 실행이 실패로 표시됩니다. 그러면 로컬 실행으로 전환하세요.
- 키워드 매칭이라 오탐과 누락이 있습니다. 시트의 `추천이유` 열을 보고 `설정` 탭이나 `config.yaml`의 목록을 계속 다듬는 것을 전제로 합니다.
- 요청 사이에 1.5초씩 쉬고 실행은 주 2회라 서버 부담은 작습니다. 그래도 링커리어 이용약관은 직접 확인하시고, 개인 용도로만 쓰세요.
