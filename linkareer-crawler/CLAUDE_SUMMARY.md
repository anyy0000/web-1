## 2. 요약할 행 고르기

다음 조건을 모두 만족하는 행이 대상이다 (한 번에 최대 30건):
- `내용요약`이 비어 있거나 `(발췌)` 또는 `(포스터 OCR)`로 시작
- `마감일`이 오늘(한국 시간) 이후

대상이 없으면 "요약할 새 공고 없음"이라고 보고하고 끝낸다.

```bash

```
- 본문이 짧은(포스터 위주) 공고는 이미지 경로가 출력된다. 그 이미지를 직접 열어 읽는다.
- 본문이 충분한 공고는 이미지를 열지 않는다 (사용량 절약).

## 4. 요약 쓰는 법
읽는 사람: 식품영양학과 대학생. 목록을 훑어보며 지원할지 고른다. 셀 하나에 들어갈 만큼 짧고 쉽게.
- **내용요약**: 무엇을 하는 공모전/활동인지 한 문장, 50자 안팎, 명사형으로 끝낸다.
  공모전이 아닌 행사·이벤트·지원사업·유료 프로그램이면 끝에 `(공모전 아님)` 또는 `(참가비 N원)`처럼 밝힌다.
  - 예) `국내산 양식 수산물로 1인 가구 간편요리·보양식을 만드는 요리 공모전`
  - 예) `당근잎차 브랜드 이이키 제품을 체험하고 SNS 콘텐츠를 만드는 서포터즈 (3개월)`
- **준비할 것**: 지원할 때 내는 것과 선정 후 해야 하는 일. 50자 안팎.
  - 예) `홈페이지 신청 후 요리 영상(10분 이내) + 완성 요리 사진 이메일 제출`
- **참가대상**: 20자 안팎. 예) `누구나`, `대학생 (재학·휴학·졸업예정)`, `만 19세 이상`, `사업장 단위, 개인 불가`
- 날짜·상금·문의처는 다른 칸에 있으니 꼭 필요할 때만 넣는다. 공고에 없는 내용은 추측하지 말고 `공고에 명시 없음`.
- `(발췌)` 같은 접두어는 붙이지 않는다.

## 5. 시트에 쓰기
- 쓰기 직전에 `ID` 열을 다시 읽어 각 ID의 현재 행 번호를 확인한다 (크롤러가 정렬을 바꿀 수 있음).
- 해당 행의 `내용요약`·`준비할 것`·`참가대상` 세 칸만 쓴다. 다른 칸(상태·메모 등)은 절대 건드리지 않는다.
- 연속된 행은 한 번에 범위로 쓰되, 중간에 대상이 아닌 행이 끼면 그 행은 기존 값을 그대로 다시 넣어 바꾸지 않는다.
